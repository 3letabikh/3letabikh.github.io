# Ali Tabikh – GIS & Remote Sensing portfolio

Live site: https://3letabikh.github.io

| Project | What it is | Tools |
|---|---|---|
| [River basins of Lebanon](https://3letabikh.github.io/river-basins/web/) | Interactive dashboard and 16-sheet atlas of Lebanon's river basins: delineation, stream network, Strahler order and morphometry from a 30 m DEM | ArcGIS Pro, arcpy, NumPy, Leaflet, Chart.js |
| [Access to health care – Baalbek-Hermel](https://3letabikh.github.io/health-access/P2_brief.pdf) | Car travel time to the nearest hospital and primary health centre, and who lives more than 30 min away | Google Earth Engine, ArcGIS Pro, Python, WorldPop, OSM |
| [Drought monitoring – Upper Litani basin](https://3letabikh.github.io/drought/P1_report.pdf) | Satellite drought indices (VCI, TCI, VHI) for 2001–2025, drought hot spots and Qaraoun reservoir change | Google Earth Engine, MODIS, CHIRPS, ArcGIS Pro, Python |

Site: plain HTML, CSS and JavaScript (no framework), light and dark theme, mobile first. Icons: Remix Icon. Fonts: Space Grotesk, Inter.
